# Source-bound scientific requirement checks (v256)

Run `python reproduce_public_requirements.py --work-dir NEW_DIRECTORY` after installing requirements.txt. No SSH, API key, hospital record, expert label or precomputed clinical score is used. GEO public human pancreatic RNA counts, PBMC metadata and pinned Bioconductor airway metadata are downloaded. Approximately 30 MB of source downloads are needed. Four donor matrices are streamed; 16 GB RAM is sufficient for the independent chunked cross-check.

The workflow executes 48 controlled source-contract cases, independently recomputes full-gene donor pseudobulk sums and three prespecified marker contrasts, then tests a 35-case extension for whole-packet identity, declared threshold provenance, missing/malformed alpha, metadata-versus-expression scope, assay availability and unsupported population scope. These case counts are engineering controls, not independent expert labels or an 83-study accuracy benchmark. Eight valid controls are retained in each test layer; layers overlap and must not be pooled as independent scientific cases.

INS beta-minus-alpha is the frozen primary worked contrast, GCG alpha-minus-beta a positive control and MS4A1 beta-minus-alpha an exploratory negative control. The actual inferential unit is four source-annotated human donors, not 8,569 cells. The paired two-sided t analysis and its 95% interval are primary; exact sign-flip and donor bootstrap are separately reported sensitivity checks. With four donors the minimum two-sided exact sign-flip P is .125; do not hide that granularity or present the familiar markers as new biology. Airway identifies cell lines, not verified distinct human donors. PBMC metadata has eight ind values and 29,065 rows including singlet/doublet/ambiguous flags: the metadata universe is reported without silently treating multiplets as additional donors or inventing an expression analysis.

Raw counts are not fabricated or imputed; every original source file is hashed. The initial unavailable airway URL remains in the intake receipt, followed by the successful pinned source amendment. Portable copies replace only the configurable workspace root and pin the already-observed airway revision; substantive scientific rules and source analysis are unchanged.
