# Data availability

No new primary data were generated. GSE241468 provides the barcode-paired
human lung multiome source; GSE291190 provides hPCLS context; GSE178361
provides normal distal-lung spatial data; and GSE47460 and GSE188464 provide
external or perturbational lung context. Raw and source-study processed data
remain under their repository accessions. This versioned repository contains
derived source tables, fold definitions, out-of-fold predictions,
negative-control outputs, model receipts, statistical reports and checksums.
No restricted participant-level data are redistributed.

# Code availability

Executable analysis code, environment lock, configurations and frozen
statistical outputs are available at
https://github.com/ahvsjags/reversome-evidence-benchmark, release
`v1.0.0-manuscript`. Third-party model weights and large raw public datasets
are excluded; accessions, acquisition instructions and SHA256 receipts identify
those dependencies. A Zenodo DOI will be added after author-controlled
deposition of this exact tag.
