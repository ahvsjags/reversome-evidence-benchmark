# Zenodo deposition checklist

The tagged GitHub release is technically ready for archival. Before minting a
DOI, the submitting author must complete these identity-dependent fields:

- verified full author list and order;
- affiliations and ORCID identifiers;
- corresponding author and contact email;
- funding and grant identifiers;
- related manuscript DOI, when available;
- final access right and community selection.

Deposit the exact `v1.0.0-manuscript` tag, then replace the null DOI in
`release_manifest.json`, `CITATION.cff`, the manuscript and the Data and Code
Availability statement. Do not mint an archive under unverified placeholder
authorship.
