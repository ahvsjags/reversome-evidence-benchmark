# Reproducibility checklist

- [x] Primary endpoint and independent unit declared.
- [x] Random seeds and bootstrap draws declared.
- [x] Formal specimen-level confidence interval and exact test released.
- [x] Fold heterogeneity distinguished from confidence intervals.
- [x] Donor/specimen leakage gates machine readable.
- [x] Degenerate dataset folds retained and excluded by explicit rule.
- [x] Missing macro-F1 policy declared.
- [x] Majority, study-only, PCA+logistic and Ridge baselines included.
- [x] Out-of-fold predictions released.
- [x] Environment freeze and checksums included.
- [x] Third-party weights excluded; provenance and licences documented.
- [ ] Author list, ORCIDs, funding and competing interests completed.
- [ ] Zenodo DOI minted for the tagged release.
